# Web Interface Guidelines

Review files for compliance with Vercel's Web Interface Guidelines.

The rules are in [guidelines.md](guidelines.md), a copy of
`vercel-labs/web-interface-guidelines/command.md` taken on 2026-10-08. Use this local copy; do not
fetch the rules from the internet.

## Usage

1. Read [guidelines.md](guidelines.md).
2. Read the files the user named (or ask which files to review).
3. Check them against every rule and report findings in the `file:line` format the guidelines give.
