# RVW-26: עוד שדות במיזוג כפילויות, החלק שמדביקים ביד

הקובץ מיועד להדבקה ידנית ב-SQL Editor של Supabase. מדביקים אותו ביד כי החיבור האוטומטי נעצר על כל קובץ שיש בו פקודת מחיקה.

## מה זה עושה

כשממזגים שתי רשומות כפולות, המערכת מוחקת את הכפילות בסוף. עד היום פקודת המחיקה ישבה בתוך פונקציית המיזוג עצמה. הקובץ הזה מוציא אותה לפונקציה קטנה ונפרדת, וכך את כל השאר (השדות החדשים שאפשר לבחור במיזוג) אפשר להעלות אוטומטית.

את הפונקציה אי אפשר להפעיל ישירות. רק פונקציית המיזוג קוראת לה, אחרי כל בדיקות ההרשאה. היא מוחקת רק ליד, איש קשר או חברה, ורק בעסק שלהם.

הקובץ רק יוצר פונקציה: כשמריצים אותו הוא לא משנה ולא מוחק שום דבר.

## מה להדביק

את הקובץ `supabase/handoff/20261006020555_merge_delete_duplicate/part1.sql`, בהדבקה אחת (כ-1,100 תווים), ולוחצים Run.

אפשר להריץ שוב בלי נזק. מריצים אותו לפני שאני מעלה את שאר השינוי.

## איך נראית הצלחה

אמור להופיע "Success. No rows returned". אם מופיעה שגיאה, לא ממשיכים ושולחים לי את הטקסט שלה.

```sql
select proname from pg_proc
 where pronamespace = 'app'::regnamespace and proname = 'merge_delete_duplicate';
```
