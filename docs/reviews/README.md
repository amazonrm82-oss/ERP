# סקירות שבועיות

כל קובץ כאן הוא סקירה אחת של מה שמוזג מאז הסקירה הקודמת. את הסקירה כותב סוכן שלא בונה, והיא לא משנה שום קובץ אחר.

- שם הקובץ הוא תאריך הסקירה, למשל `2026-10-12.md`.
- כל ממצא מקבל מזהה `RVW-<מספר>`. המספור ממשיך מקובץ לקובץ.
- חומרה: `קריטי` (דליפה בין עסקים, עקיפת כניסה, אובדן נתונים), `גבוה`, `בינוני`, `נמוך`.
- העמודה "טיפול" שייכת לסוכן המוביל: הקומיט שתיקן, או למה הממצא נשאר כמו שהוא.
- ממצא הוא טענה שבודקים מול הקוד לפני שמתקנים, לא הוראה.
- כל עוד המאגר ציבורי, חולשה שאפשר לנצל באתר החי לא נכתבת כאן. היא נמסרת לבעל המוצר, והוא מעביר אותה ל-Claude Code.

הכללים לסוכן המוביל נמצאים ב-`CLAUDE.md` ("Weekly review").
