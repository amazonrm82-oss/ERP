- **בעלים**: הכול, כולל העברת בעלות, מינוי מנהלי מערכת וייצוא מלא.
- **מנהל מערכת**: מנהל את העסק, המשתמשים וההגדרות, ועורך את כל הרשומות.
- **מנהל צוות**: עורך את הרשומות של הצוותים שהוא מנהל, רואה דוחות ותמונת מצב, ומייבא.
- **משתמש**: יוצר רשומות ועורך את מה ששלו.
- **צופה**: רואה ולא משנה.

מחיקה לסל המחזור מותרת לבעלים, למנהלי מערכת ולמנהלי צוות (ברשומות של הצוותים שלהם).

## מי רואה מה

ב**הגדרות** ← **פרטי העסק**, ב**מי רואה את הרשומות**, בוחרים: **כל העסק**, **לפי צוות** או **רק שלי**. ההגדרה חלה על לידים, אנשי קשר, חברות ועסקאות.

## שינוי תפקיד והשבתה

ב**הגדרות** ← **משתמשים** משנים תפקיד ולוחצים **שמירה**. עובד שעזב משביתים ב**השבתה**. הנתונים שלו נשארים, ואפשר להחזיר אותו ב**החזרה לפעילות**.

## עובד שעוזב

לפני שמשביתים עובד, מעבירים את הרשומות שלו: ב**הגדרות** ← **משתמשים** לוחצים **העברת רשומות** ליד השם, בוחרים **למי להעביר** ולוחצים **העברת כל הרשומות**. עוברים הלידים, אנשי הקשר, החברות, העסקאות (גם בסל המחזור) והמשימות. המקבל מקבל התראה אחת עם הסיכום.

## העברת בעלות

רק הבעלים: ב**העברת בעלות** בוחרים את **הבעלים החדש**, מאשרים ולוחצים **העברת הבעלות**. הבעלים הקודם הופך למנהל מערכת.
