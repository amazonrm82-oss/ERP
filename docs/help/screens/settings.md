- כאן מתאימים את המערכת לעסק: משתמשים, תהליכי מכירה, שדות וטפסים.
- ההגדרות מסודרות בקבוצות; לוחצים על קבוצה כדי להיכנס.
- ההגדרות האישיות שלכם נמצאות ב"החשבון שלי" בתפריט המשתמש.
