ב"הגדרות" מוסיפים עובדים ומתאימים את המערכת לעסק: שלבים, שדות וטפסים.

בכל מסך ראשי יש כפתור "?" עם הסבר קצר, ומרכז העזרה נמצא בתפריט החשבון. את הסיור אפשר לראות שוב משם.
